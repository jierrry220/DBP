# 🐻 Debear Party - Frontend

Official frontend application for Debear Party - A GameFi platform on Berachain.

## 🌟 Features

- 🏠 **Landing Page** - Modern, animated homepage with particle effects
- 💱 **Token Swap** - Decentralized token exchange interface
- 🎫 **Pass NFT** - NFT minting and management system
- ⚡ **T-Engine** - Token engine and pool management
- 🎮 **GameFi Platform** - Game balance management with password protection
- 🌐 **Multi-language** - Support for English and Traditional Chinese
- 📱 **Responsive Design** - Optimized for both desktop and mobile

## 🚀 Deployment

This project is deployed on [Zeabur](https://zeabur.com).

### Prerequisites
- Static hosting service (Zeabur, Vercel, Netlify, etc.)
- No build process required - pure HTML/CSS/JS

### Deploy to Zeabur
1. Fork this repository
2. Connect to Zeabur
3. Deploy as a static site
4. Done! 🎉
